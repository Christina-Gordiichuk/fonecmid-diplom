# Инструкция начальной настройки ВКМ

Документ описывает минимальные шаги для включения функциональности ВКМ в рабочей базе `Управление IT-фирмой`.

## 1. Обновление конфигурации

1. Загрузите изменения конфигурации в информационную базу.
2. Выполните обновление базы данных.
3. Перезапустите сеанс пользователя.

## 2. Первичное заполнение НСИ и констант

1. В перечислении видов договоров используйте значение `Абонентское обслуживание`.
2. В карточках `Договоры контрагентов` для абонентских договоров заполните:
   - `ВКМ_ДатаНачалаДействия`;
   - `ВКМ_ДатаОкончанияДействия`;
   - `ВКМ_СуммаАбонентскойПлаты`;
   - `ВКМ_СтоимостьЧасаРаботы`.
3. Заполните константы интеграции Telegram:
   - `ВКМ_ТокенTelegramБота`;
   - `ВКМ_ИдентификаторЧатаTelegram`.
4. Заполните регистр `ВКМ_УсловияОплатыСотрудников` (оклад, процент от работ).

## 3. Назначение ролей и профилей

Создайте (или обновите) группы доступа и назначьте поставляемые профили:

- `Специалист` (`ВКМ_Специалист`);
- `Менеджер` (`ВКМ_Менеджер`);
- `БухгалтерИТФирмы` (`ВКМ_БухгалтерИТФирмы`);
- `КадровикРасчетчик` (`ВКМ_КадровикРасчетчик`).

Если профили не появились автоматически, выполните обновление профилей групп доступа через подсистему администрирования.

## 4. Регламентные задания

Проверьте включение задания `ВКМ_УведомленияПоОбслуживанию`.

Рекомендуемые параметры:
- запуск каждые 10 минут;
- перезапуск при ошибке: 3 попытки.

## 5. Проверка работоспособности

1. Сформируйте несколько документов `Реализация товаров и услуг` по абонентским договорам.
2. Убедитесь, что формируются движения по регистрам:
   - `ВКМ_ВыполненныеКлиентуРаботы`;
   - `ВКМ_ВыполненныеСотрудникомРаботы`;
   - `ВКМ_ВзаиморасчетыССотрудниками` (при использовании в расчетных сценариях).
3. Сформируйте отчеты:
   - `ВКМ_АнализОбслуживанияКлиентов`;
   - `ВКМ_ВыработкаСпециалистов`;
   - `ВКМ_НачисленияСотрудников`;
   - `ВКМ_РасчетыССотрудниками`;
   - `ВКМ_РасходЗапланированныхОтпусков`.
