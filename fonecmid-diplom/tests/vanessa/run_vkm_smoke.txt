Инструкция запуска Vanessa сценария ВКМ (smoke + e2e)

1. Подготовить информационную базу:
   - заполнить константы `ВКМ_ТокенTelegramБота` и `ВКМ_ИдентификаторЧатаTelegram` (для режима отправки уведомлений);
   - добавить в регистр `ВКМ_УсловияОплатыСотрудников` строки по тестовым сотрудникам;
   - убедиться, что в базе есть минимум 5 документов `Заказ покупателя` и `Реализация товаров и услуг`;
   - добавить тестовый документ `ВКМ_ОбслуживаниеКлиента` по абонентскому договору;
   - при необходимости сравнения подготовить эталонный макет `ВКМ_Эталон_НачисленияСотрудников` отдельным шагом вне текущего smoke-сценария;
   - убедиться, что тестовые пользователи и профили (`МенеджерПоОбслуживанию`, `Специалист`, `БухгалтерИТФирмы`) назначены и активны.
2. Установить Vanessa Automation и библиотеку шагов VA в тестовую базу.
3. Запустить 1С в режиме TestClient и открыть обработку Vanessa Automation.
4. В настройках Vanessa указать каталог фич: `tests/vanessa/features`.
5. Базовый устойчивый прогон (без эталона): запускать `ВКМ_МассовоеСозданиеАктов.feature` с исключением тега `@etalon`.
6. Полный e2e с эталоном: запускать тот же feature c включением сценария `@etalon` только после подготовки макета `ВКМ_Эталон_НачисленияСотрудников`.
7. Проверить, что сценарий проходит роли менеджер -> специалист -> бухгалтер без падений шагов.
8. Проверить, что после повторного заполнения таблицы в обработке присутствует минимум одна строка со статусом `Акт уже создан`.
9. Для прогона с `@etalon` подтвердить, что шаг сравнения табличного документа завершается без расхождений.

Ожидаемый результат:
- открывается обработка "Массовое создание актов";
- по команде запуска выводится сообщение о старте фонового задания;
- в таблице заказов фиксируется факт создания минимум одного акта (статус `Акт уже создан`);
- формируются отчеты "Анализ обслуживания клиентов", "Выработка специалистов", "Начисления сотрудников" и "Расчеты с сотрудниками";
- результат отчета "Начисления сотрудников" формируется;
- при запуске сценария `@etalon` результат отчета совпадает с макетом `ВКМ_Эталон_НачисленияСотрудников`.
