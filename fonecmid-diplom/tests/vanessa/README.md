# Автотест Vanessa Automation — заявки клиентов

Сценарий лежит в `tests/vanessa/features` и закрывает шаги из ТЗ:

1. менеджер планирует несколько обслуживаний;
2. специалист закрывает эти обслуживания;
3. бухгалтер массово создаёт акты;
4. формируется отчёт «Анализ выставленных актов» и сравнивается с эталоном.

Основная фича: `features/ВКМ_ЗаявкиКлиентовE2E.feature`.  
Дополнительный smoke по обработке актов: `features/ВКМ_МассовоеСозданиеАктов.feature`.

## 1. Подготовка информационной базы

1. Загрузите конфигурацию из исходников EDT и выполните обновление БД.
2. Создайте пользователей ИБ (пустой пароль допустим для учебной базы):

   | Логин        | Профиль групп доступа   |
   |--------------|-------------------------|
   | Администратор | Администратор           |
   | Менеджер      | Менеджер                |
   | Специалист    | Специалист              |
   | Бухгалтер     | БухгалтерИТФирмы        |

   Имя пользователя в справочнике `Пользователи` для специалиста должно быть **Специалист**.
3. Под администратором заполните демо-данные обработкой `tools/VKM_FillDemoData.epf` либо вручную:

   - организация `ВКМ IT-фирма` (если в базе уже есть организация, в фиче замените строку выбора на её наименование);
   - контрагенты `ВКМ Клиент Альфа`, `ВКМ Клиент Бета`;
   - абонентские договоры `ВКМ Договор Альфа`, `ВКМ Договор Бета`;
   - константы `ВКМ_НоменклатураАбонентскаяПлата`, `ВКМ_НоменклатураРаботыСпециалиста`;
   - строка регистра `ВКМ_УсловияОплатыСотрудников` на текущего специалиста (оклад и процент; ноль процента допустим, пустое значение — нет).
4. Перезапишите профили групп доступа, если роли ВКМ не появились у пользователей.

## 2. Окружение Vanessa Automation

1. Установите [Vanessa Automation](https://pr-mex.github.io/vanessa-automation/dev/) и библиотеку стандартных шагов.
2. Запустите тонкий клиент в режиме тестирования (TestClient) и откройте обработку Vanessa Automation.
3. В настройках укажите каталог фич:

   `fonecmid-diplom/tests/vanessa/features`

4. В таблице клиентов тестирования добавьте три клиента:

   | Имя        | Строка запуска                          |
   |------------|-----------------------------------------|
   | Менеджер   | `/N"Менеджер" /P""`                     |
   | Специалист | `/N"Специалист" /P""`                   |
   | Бухгалтер  | `/N"Бухгалтер" /P""`                    |

   Порт и путь к базе возьмите из вашего профиля запуска.

## 3. Запуск

Базовый прогон по ТЗ без внешнего макета эталона:

- запускайте `ВКМ_ЗаявкиКлиентовE2E.feature`;
- исключите тег `@etalon`.

Полный прогон с эталоном табличного документа:

1. Один раз сформируйте отчёт вручную под бухгалтером за текущий месяц.
2. В Vanessa сохраните макет эталона с именем `ЭталонАнализВыставленныхАктов` рядом с фичей (команда получения состояния табличного документа).
3. Запустите ту же фичу с тегом `@etalon`.

Дополнительный smoke только обработки актов: `ВКМ_МассовоеСозданиеАктов.feature`.

## 4. Ожидаемый результат

- созданы две заявки с комментариями `Автотест: заявка 1` и `Автотест: заявка 2`;
- обе заявки проведены специалистом со строками выполненных работ;
- обработка «Массовое создание актов» заполняет колонку реализации;
- отчёт «Анализ обслуживания клиентов» заполнен и содержит клиентов Альфа и Бета;
- сценарий `@etalon` совпадает с сохранённым макетом.
