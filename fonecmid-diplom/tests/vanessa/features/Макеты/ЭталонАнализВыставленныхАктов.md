# Эталон отчёта «Анализ выставленных актов»

Эталон к сценарию `ВКМ_ЗаявкиКлиентовE2E.feature`.
Сравнение выполняется шагами Vanessa Automation в фиче.

Предусловия договоров автотеста:

- `ВКМ Договор Альфа`: стоимость часа = 5
- `ВКМ Договор Бета`: стоимость часа = 5

Сценарий проводит по каждому клиенту 1 час работ. Тогда:

| Клиент           | Договор           | Сумма к выставлению | Фактическая сумма по работам |
|------------------|-------------------|---------------------|------------------------------|
| ВКМ Клиент Альфа | ВКМ Договор Альфа | 5,00                | 5,00                         |
| ВКМ Клиент Бета  | ВКМ Договор Бета  | 5,00                | 5,00                         |
| Итого            |                   | 10,00               | 10,00                        |

Если массовое создание актов не сработало, фактическая сумма по работам будет 0,00, и сравнение с эталоном упадёт.
